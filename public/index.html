🧬 Voice Cloning Studio

Reference voices

Clone any voice from a 10–20 second recording. The clip is converted to mono 44.1 kHz, trimmed to its cleanest stretch of speech and measured before upload — Fish reproduces a recording's noise and frequency response along with the voice.

Letters, numbers, spaces, - and _ only.

Must match the audio — a wrong transcript degrades the clone.

⚠ A voice you create here lives in the running Fish session, not in this project. Restarting the notebook rebuilds the reference folder from the voice-pack cell, and anything added afterwards is gone with it — the list below always shows what the server has right now. To keep a voice, add its clip and transcript to the voice-pack cell in the notebook.

How to Use VoiceCraft

        
      

      
      

        
        

          
Step 1 — Create a Free Kaggle Account

          

            Create a free account on Kaggle and sign in. You may need to complete phone verification in your Kaggle settings to unlock access to GPU accelerators.
          

          Open Kaggle ↗
        

        
        
        

          
Step 2 — Download the VoiceCraft Kaggle Notebook

          

            This file contains the code required to run the VoiceCraft backend engine on Kaggle's servers. You will need to import it into Kaggle.
          

          ⬇ Download Notebook
        

        
        
        

          
Step 3 — Set Up the Kaggle Notebook

          

            Go to Kaggle, click Create > New Notebook, and use the File > Import Notebook option to upload the file you just downloaded.
          

          

            Once imported, open the Accelerator settings (usually in the right sidebar) and configure the notebook to use a GPU. Select the T4 GPU if available.
          

        


        
        

          
Step 4 — Set Up ngrok

          

            We use an ngrok tunnel to securely connect the VoiceCraft web application to your Kaggle instance. Create a free ngrok account to get your authentication token. Never share your token publicly. Enter your token into the designated cell in the Kaggle notebook.
          

          Open ngrok ↗
        


        
        

          
Step 5 — Start VoiceCraft in Kaggle

          

            Execute the cells in the Kaggle notebook in order (Shift + Enter). This will install the required dependencies and start the VoiceCraft backend engine. Wait until the final cell confirms the server is running.
          

        


        
        

          
Step 6 — Start the ngrok Tunnel

          

            Run the final ngrok cell in the notebook. It will generate a public URL (e.g. https://abcd.ngrok-free.app). This URL is your public endpoint. Copy it to your clipboard.
          

        


        
        

          
Step 7 — Connect the Endpoint to VoiceCraft

          

            Return to this application, open Settings, and paste your ngrok endpoint URL into the VoiceCraft Backend field. Click Test connection to verify that the app can communicate with Kaggle.
          

          
        


        
        

          
Step 8 — Add a Voice Reference

          

            A voice reference is a 10-20 second audio sample of a voice you want VoiceCraft to clone. Ensure it is clear, contains only one speaker, and has no background music. In the VoiceCraft dashboard, scroll down to the Voice Cloning Studio section to upload your .mp3, .wav, .ogg, .flac, or .m4a sample. Provide an accurate transcript of exactly what is being said in the recording.
          

        


        
        

          
Step 9 — Generate Voice

          

            Once your voice reference is uploaded, type your script in the main input area and click Generate Speech. The audio will be rendered using your cloned voice! If the backend disconnects or your session ends, simply restart the notebook, grab the new ngrok URL, and update your Settings.
